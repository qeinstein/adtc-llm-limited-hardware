Local model note

The first message may take longer.

Jamii Afya warms the local model and may think before showing an answer. Expect the first message to be the slowest; later messages are usually faster. Longer messages also take more time to process.

Ask a question.

Jamii Afya answers general and health questions, using the language of your message and adding relevant English offline reference material when available. For health decisions, it supports clinical judgement — it does not replace it.

Runs entirely offline on this machine. Decision support only — always confirm with a qualified clinician.
