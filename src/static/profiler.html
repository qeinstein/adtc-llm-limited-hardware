How to read it

Strong evidence, deliberately limited claims.

What it proves

A 12.26 GB sparse model artifact can execute through the bounded runtime with a roughly 2.5 GB measured resident working set and a 16.0 tok/s official profiler headline.

What it does not prove

It does not prove frontier-server latency, phone deployment, clinician validation, or production medical safety. Even 35B remains a compromise against the real target.

Throughput wording

The profiler observed individual runs at 16.46 and 15.5 tok/s. The submission uses the rounded 16.0 tok/s headline.

Weight provenance

No weight-level fine-tuning was performed. The result comes from runtime systems engineering, selective quantization, sparse execution, and bounded staging.

Full methodology, commit identities, platform details, and limitations are documented in the repository's REPORT.md. Read the architecture to see how the memory boundary works.
